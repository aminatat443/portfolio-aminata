# Portfolio Aminata Traore

Portfolio React moderne pour Aminata Traore, developpeuse Full-Stack, DevOps et cybersecurite basee a Dakar.

## Demarrage

```bash
npm install
npm run dev
```

Le site sera disponible sur l'adresse locale indiquee par Vite.

## Personnalisation rapide

- Modifier les projets, competences et experiences dans `src/data/portfolio.js`.
- Modifier l'email, le telephone, WhatsApp et les liens sociaux dans `src/App.jsx`.
- Remplacer ou ajouter le CV dans `public/cv-aminata-traore.pdf` si besoin.
